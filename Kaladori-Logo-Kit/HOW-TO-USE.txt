KALADORI — LOGO KIT
===================

01-horizontal-main  Main logo: website header, visiting card, letterhead, bills
02-stacked          Square / tall spaces: carry bags, posters, Instagram posts
03-icon             Needle mark alone: favicon, watermark, small spaces
04-wordmark         Name only
05-badge            Round seal: stickers, tags, pin badge, packaging
06-website          Ready web files (see below)
07-png              Transparent PNGs (Canva, WhatsApp, Word) + profile pictures
08-print-pdf        Vector PDFs for the printing press

Colour versions
  color    -> light backgrounds (black + maroon)
  reverse  -> dark backgrounds (cream + blush)
  black / white / maroon -> 1-colour print: plastic bags, stamps, screen print

Website (Next.js app router)
  Put favicon.ico, icon.svg, apple-icon.png, opengraph-image.png in /app
  -> Next.js adds the <head> tags automatically.
  Header logo: logo.svg (light header) or logo-dark-bg.svg (dark header) in /public
  icon-192.png / icon-512.png -> web manifest (PWA)

Colours
  Needle Black   #1A1A1A   C0 M0 Y0 K90
  Thread Maroon  #9A2D4C   C0 M71 Y51 K40 (approx.)
  Cream          #F8F5EE   C0 M1 Y4 K3
  Blush          #F2B8C6   C0 M24 Y18 K5 (thread on dark backgrounds)

Font in the logo: Bodoni Moda Medium (free Google Font).
All text is already converted to outlines - no font install needed.

Minimum size: horizontal 30 mm / 140 px wide, icon 8 mm / 24 px tall, badge 20 mm.
Plastic bags / screen print: use a 1-colour file, horizontal at least 80 mm wide.
